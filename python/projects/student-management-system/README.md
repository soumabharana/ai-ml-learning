# Student Management System

A command-line Student Management System developed from my Python course capstone.

## Features

- Add new students
- Display student records
- Search by roll number or name
- Find the class topper
- Calculate average marks
- Calculate grades
- Save student data to a text file
- Handle basic invalid input

## Concepts Practiced

- Lists and dictionaries
- Functions
- Loops and conditionals
- Lambda functions
- Object-oriented programming
- File handling
- Exception handling
- User input and menu-driven programs

## Origin

This project began as my Python course capstone and is being organized and improved as part of my ongoing AI/ML learning journey.
